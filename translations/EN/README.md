## 🚀 What is this?

**Clinical Statistical Inferences** is an interactive analytics application that demonstrates how modern statistical methodology, machine learning and visualization transform raw clinical trial data into **decision-grade insights**.

The platform reproduces the core analytical logic used in pharmaceutical research, CRO environments, and regulatory reporting — while making the results understandable for medical, business, and executive stakeholders.

👉 Think **Tables, Listings & Figures (TLFs)** — but dynamic, visual and explorable.

---

## 🎯 Business Impact

This project shows how to:

- evaluate **treatment effectiveness**
- quantify **uncertainty & risk**
- compare **study arms**
- detect **patient subgroups**
- monitor **efficacy over time**
- support **evidence-based decisions**

It bridges the gap between **statistical rigor** and **communication clarity**.

---

## 🧠 Statistical & Analytical Coverage

The application includes interactive demonstrations of:

| Area | What decision makers learn |
|------|-----------------------------|
| Inferential Statistics | Is the treatment effect real or random? |
| Regression / Dose Response | What dosage maximizes benefit? |
| ANOVA | Which therapy performs best? |
| Chi-Square | Are outcome differences associated with treatment? |
| Survival Analysis | Which drug prolongs life longer? |
| Meta-Analysis | What is the overall evidence across studies? |
| Bayesian Updating | How does certainty improve with new data? |
| Cluster Analysis | Which patient profiles behave similarly? |
| Time Series | How does efficacy evolve? |
| Intention-To-Treat | Are conclusions robust to dropouts? |

## 🏗 Architecture Overview

**Frontend:** Streamlit  
**Computation:** NumPy, SciPy  
**Machine Learning:** scikit-learn  
**Survival Models:** lifelines  
**Visualization:** Plotly  
**Data Handling:** pandas  

Modular design:

```

app.py          → UI & navigation
plots.py        → statistical engines & visual output
utilities.py    → explanations & domain knowledge

````
