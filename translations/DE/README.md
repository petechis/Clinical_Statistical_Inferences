## 🚀 Was ist das?

**Klinische Statistische Inferenz** ist eine interaktive Analytics-Applikation, die zeigt, wie moderne Statistik, Machine Learning und Visualisierung klinische Studiendaten in **entscheidungsrelevante Erkenntnisse** verwandeln.

Die Plattform bildet typische Analyseprozesse aus Pharmaunternehmen, CROs und regulatorischem Reporting ab – jedoch visuell, intuitiv und für verschiedene Stakeholder verständlich.

👉 Klassische **TLFs (Tables, Listings & Figures)** – neu gedacht, interaktiv.

---

## 🎯 Geschäftlicher Mehrwert

Das Projekt demonstriert, wie man:

- **Wirksamkeit von Therapien** bewertet  
- **Unsicherheiten** quantifiziert  
- Behandlungsarme vergleicht  
- Patientensegmente identifiziert  
- Trends über Zeit erkennt  
- datenbasierte Entscheidungen unterstützt  

Es verbindet **statistische Präzision** mit **klarer Kommunikation**.

## 🧠 Abgedeckte Methoden

| Bereich | Welche Frage wird beantwortet |
|--------|-------------------------------|
| Inferenzstatistik | Ist der Effekt signifikant? |
| Regression / Dosis | Welche Dosis ist optimal? |
| ANOVA | Welche Therapie ist überlegen? |
| Chi-Quadrat | Hängt das Ergebnis von der Behandlung ab? |
| Survival Analyse | Welche Behandlung verlängert das Überleben? |
| Meta-Analyse | Wie stark ist die Gesamtevidenz? |
| Bayesianisch | Wie verbessert neue Evidenz die Sicherheit? |
| Cluster | Welche Patienten ähneln sich? |
| Zeitreihen | Wie entwickelt sich die Wirksamkeit? |
| ITT | Bleiben Ergebnisse trotz Abbrüchen stabil? |
